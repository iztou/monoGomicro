二、五个 Maven 模块的职责边界

monogomicro-core（无框架纯库）

所有算法的家：解析、图、分区、指标、报告
ProjectScanner JavaParser 符号解析，扫出类与依赖边
MavenClasspathResolver 调 mvn 拿依赖 jar 供符号求解
DependencyGraph 加权有向图（邻接表）
TraceAnalyzer 轨迹 → 业务用例 → 动态权重
LouvainPartitioner 社区发现（手写两阶段）
AnnealingRefiner 模拟退火多目标精化
SharedKernelDetector 高扇入跨社区类剥离
JsonIO / ConsoleReporter 报告读写

monogomicro-agent（shade fat jar）

运行时轨迹采集探针
TraceAgent.premain ByteBuddy Advice 织入 enter/exit
TraceRecorder 线程本地缓冲落盘（低开销）
挂载方式：-javaagent:agent.jar=out=…,include=…,entry=…

monogomicro-codegen

分区 → 可编译的微服务工程
MicroserviceGenerator 编排：骨架/闭包/提升/迁移
RpcBridgeGenerator 跨服务调用改写为 REST 双端
PomReader 读取原单体 pom 抽依赖元信息

monogomicro-cli（fat jar → m2m.jar）

唯一入口，把四阶段串成命令行产品
Main picocli 四个子命令
analyze / partition / trace / generate
各命令只做「参数 → core/codegen → JSON 落盘」的胶水

monogomicro-web（Spring Boot 3）

本地可视化控制台（薄 REST + 单页）
WorkspaceController load / state / move / generate
ConsoleState 会话内分区状态与指标重算
static/index.html D3 v7 力导向图 + 拖拽

三、技术选型：每个技术解决什么问题

技术所在模块作用 & 为什么选它
解析与图
JavaParser 3.26 + Symbol Solvercore把 Java 源码解析成 AST 并做符号级类型解析（不是文本匹配）。CombinedTypeSolver 组合三种求解器：ReflectionTypeSolver（JDK 类）+ JavaParserTypeSolver（项目源码）+ JarTypeSolver×N（依赖 jar）。继承/泛型参数/字段注解/枚举/@interface/类字面量/varargs 全覆盖，且每条边带来源行号——审计级精度是分区质量的地基。
MavenInvoker（mvn build-classpath）core不重复造轮子：直接调 mvn dependency:build-classpath 拿依赖 jar 列表，喂给 JarTypeSolver，解决「字段类型声明在依赖 jar 里」的符号解析。
Louvain 社区发现（手写）core图聚类经典算法：局部移动 + 图聚合两阶段循环，最大化模度 Q。对 980 条边的规模毫秒级出结果，先给出「天然社团结构」的粗解。
模拟退火（手写）coreLouvain 只优化模度单一目标；退火在它的解上继续优化业务多目标：0.5·跨服务通信占比 + 0.3·用例跨度（Mono2Micro 核心洞察）+ 0.2·规模失衡度。接受劣解的概率扰动避免陷入局部最优。
运行时采集
ByteBuddy 1.15 + Java Instrumentationagentpremain 阶段对业务类做 Advice 织入（方法 enter/exit 各插一行记录）。不改一行目标项目源码、无侵入。相比手写字节码或 CGLIB，Advice API 以字符串模板方式织入，版本升级兼容性好。TraceRecorder 线程本地缓冲后落盘，开销可控。
工程生成
字符串模板代码生成codegen微服务 pom / RPC 客户端 / Controller 桥全部模板化生成。铁律：服务间禁止类级依赖——跨服务引用要么提升进 common，要么走 REST 桥；内核依赖闭包展开，保证生成物开箱 mvn compile 通过。
粘合与交付
picocli 4.7cli声明式子命令 + 类型安全选项 + 自动 --help。四个子命令对应流水线四阶段，零样板代码。
Jackson 2.17coreanalysis.json / partition.json 的读写。JSON 作为阶段间数据契约，任何阶段可独立重跑、可被 web 复用。
Spring Boot 3.3（仅 web 模块）web只做薄 REST 层（4 个端点）+ 静态页托管。刻意不让 core 依赖任何框架——core 是可复用的纯算法库。
D3.js v7web 前端力导向图渲染分区结果，节点可拖拽到别的服务、指标实时重算——「人在环」的分区编辑器。
Maven Shadeagent / cli打成可执行 fat jar：agent 需要独立成 jar 才能被 -javaagent 挂载；cli 产出单文件 m2m.jar。
SLF4J + JUnit 5全部门面日志（core 只依赖 API，绑定留给使用方）；5 个单测覆盖 Louvain 双簇/单社区/空图与轨迹交织解析。

四、关键算法速查

边权重：继承 3 / 字段 2 / 方法调用·参数·注解·构造 1（按语义强度）
双图融合：w = α·静态/max(静态) + β·动态/max(动态)（默认 0.5/0.5），×1000 取整——否则小数权重被整型截断成 0，图直接失联（实测踩过的坑）
Louvain：随机序遍历节点 → 移到模度增益最大社区 → 收敛后图聚合（节点=社区）→ 下一层；层级结果还原成类 → 社区映射
退火目标：0.5·跨服务通信占比 + 0.3·用例跨度 + 0.2·规模失衡度，温度逐降，劣解按 e^(-Δ/T) 概率接受
共享内核：扇入高且横跨 ≥3 社区的类判为共享 → 剥离进 common；生成期再做内核依赖闭包 + 跨服务共享类提升，兜住「服务间禁止类级依赖」的铁律
